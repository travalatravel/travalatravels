# Travala.com Homepage Topology

Source: https://www.travala.com/ (extracted 2026-06-10)

## Section order (top → bottom)

1. **App install banner** — dismissible mobile app promo
2. **Header** — logo, nav tabs, locale/currency, login/register; transparent over hero, solid on scroll
3. **Hero** — full-width background image, headline, search widget (Stays/Flights/Car Rental/Activities)
4. **Feature bar** — 4 columns: support, payments, AVA rewards, price guarantee
5. **Worldwide destinations** — continent tabs, countries/cities/hotels carousels
6. **Top unique properties** — property type cards (Hotel, Villa, Apartment, …)
7. **Blog inspiration** — “Where To Go & What To See” carousel
8. **Travel guides** — categorized article lists
9. **Payment / crypto** — accepted payment methods
10. **FAQs**
11. **Footer** — explore links, social, payment logos

## Interaction models

| Section | Model |
|---------|--------|
| Header | Scroll-driven background (transparent → solid) |
| Search tabs | Click-driven tab switch |
| Destinations | Click continent → updates carousels |
| Blog / property carousels | Horizontal scroll / drag |
| Travel guides | Click category → swap list |
| FAQ | Click accordion |
